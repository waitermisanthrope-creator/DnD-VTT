# Промпт для настройки почты Supabase

Помоги настроить Supabase Cloud для основного DnD-VTT на Windows и Android.
Проект уже создан: https://rrjqxbfgwsjhgshajnob.supabase.co. Публичный
publishable key встроен в приложение. SQL-миграция таблиц и RLS выполнена;
тестовые SQL-фикстуры в рабочем проекте запускать нельзя.

Нужны регистрация по почте и паролю, подтверждение почты и восстановление
пароля. Проведи пошагово по настройке custom SMTP: сначала выясни, есть ли
мой домен и почтовый сервис; если нет, предложи доступный вариант для начала.
Объясни настройки отправителя, необходимые DNS-записи, лимиты отправки и
Email Auth. Не отключай подтверждение почты как окончательное решение.

Важно: приложение подтверждает почту и восстанавливает доступ кодом внутри
приложения. В шаблонах Confirm signup и Reset password нужен {{ .Token }}.
Для подтверждения используется /auth/v1/verify с type=signup, для сброса
с type=recovery; после проверки кода задаётся новый пароль. Обработчик
возврата по ссылке в Windows/Android пока не реализован — не считай, что
изменение Site URL или redirect URL само добавит эту возможность.

Не проси пароли, SMTP-секреты или service_role ключ в чат. Объясни, где
ввести их напрямую в настройках сервиса. SMTP хранится только в Supabase;
в приложение его добавлять нельзя. Используй актуальный интерфейс сервиса.

В конце дай список настроек, публичных параметров для разработчика и
результаты реальной проверки: регистрация нового адреса, получение письма,
подтверждение, вход и восстановление пароля. Не утверждай, что всё работает,
пока проверки не выполнены. Для проверки синхронизации отдельно нужно
войти одним аккаунтом на Windows и Android и передать персонажа.
