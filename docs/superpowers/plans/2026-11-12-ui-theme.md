# UI theme foundation Implementation Plan

**Goal:** Extend the existing IMGUI appearance preferences for stage 1 of the owner's specification.
**Architecture:** Keep `theme` and settings version 1; add an optional opaque RGB HEX override. Missing/invalid optional data falls back to the legacy theme without discarding other settings. Cache semantic styles and restore the source skin before disposing dependent resources. Preserve wallet styles and dimensions.
**Tech Stack:** Unity 6000.3.26f1, C#, existing net8 source harness and Unity editor validation.
**Spec:** Owner's stage 1 request in this session; implementation authorized explicitly, no extra design approval or delegation cycle needed.

## Constraints and decisions
- Branch from fetched `origin/experiment/unity-vtt` (4a68a02c, version 1.00.40). Do not import unrelated changes or alter existing Homebrew filtering.
- No wallet, game rules, network, release/version, orientation or swipe changes.
- Preset RGB values are technical defaults, replaceable centrally; art direction remains outside this task.
- Accent selection persists immediately; other draft preferences still require the existing Save action.
- HEX accepts exactly six RGB digits, optional # and surrounding whitespace; reject alpha, names and shorthand.
- Dark surfaces retain their colors. Derive readable text from the chosen accent; use contrast >=4.5:1.
