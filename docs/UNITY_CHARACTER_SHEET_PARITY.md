## Контракт и проверка

`unity/Tools/sync_character_sheet.cjs` исполняет текущие локальные исходники main в Node VM без сети: генерирует 60 JS эталонов (уровни 1–20 × владение 0/1/2; в том числе мультикласс), конфигурацию навыков, 402 заклинания, 188 предметов и provenance. Дополнительно исполняет реальные Inventory.js/notes.js/Inventory-weight-tracker.js для эталонов добавления/объединения/удаления пяти категорий, удаления папок/заметок и 12 вариантов веса/итоговой нагрузки. Скрипт отказывается работать в другой ветке или при расхождении используемых исходников с main.

`CharacterSheetValidation.Validate` сравнивает C# с эталонами, проверяет изменение single/array/wrapper, изоляцию второго героя, сохранение неизвестных полей/вложенных предметов/состояний класса/старого HP, отказ при смене ID/будущей схеме, запись/перезагрузку/резервную копию. Вызывается также перед обоими migration builds. Это проверка базовых формул, а не всех правил main.

Удаление подтверждается внутри листа; перед применением сверяются ID персонажа и исходное содержимое удаляемой записи. Изменённая/перемещённая запись отклоняется. Расчёт веса повторяет текущий main, включая плоский обход категорий и его соглашения о единицах/нулевом количестве; не выдаёт новый физический расчёт содержимого контейнеров. Штрафы и блокировка перегруза пока не применяются.

Локальный файл Unity: `Application.persistentDataPath/dnd_multi_characters_v2.json`. Создание героя сохраняет архив сразу; последующие правки — кнопкой **Сохранить на этом устройстве**; `*.pending` заменяет основной файл атомарно, предыдущий остаётся в `*.bak`. Старые браузерные/Electron/WebView данные и Supabase не записываются. До сохранения доступен экспорт изменённого архива; исходный импорт остаётся отдельно доступен без изменений. Не подключать live cloud до реализации протокола CAS и контрактных тестов.

Продолжение: сначала полноценные операции листа и справочники (создание/уровень/расы/инвентарь/заметки/дайсы), затем классовые команды с исходными pending/source/resource контрактами и fixtures. Карту не выдавать за завершение листа. Статус всего переноса остаётся **НЕ ВЫПОЛНЕНО**.
