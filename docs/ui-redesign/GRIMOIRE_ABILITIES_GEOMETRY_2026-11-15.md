## Выполненная работа с кодом

- Убрана лишняя строка кнопок «Вернуть»/«Подробнее» в **свёрнутых** карточках умений. Нажатие по заголовку раскрывает расширенные сведения; возврат применения доступен там же.
- Все раскрывающиеся состояния новой страницы откладываются до IMGUI Layout: не меняют число GUILayout-контролов прямо во время MouseUp.
- Счётчики ячеек рисуются в фиксированных прямоугольниках внутри общей строки. Малый 18px визуальный круг вписан в сенсорную область 22×26 — ограничение компактного эталона; полноценные удобные сенсорные зоны нужно проверить при QA.
- Убрана всегда видимая кнопка редактирования ячеек из центральной декоративной панели — редактор сохранён в нижнем разделе параметров.
- Кнопка «Свой приём» тоже перенесена в доступную нижнюю секцию, без изменения действия.
- Добавлены `AbilitySpellMeta` и `AbilitySearchHint`, сокращено **только отображение** очень длинных времени/дистанции (в JSON не меняются), оформлена строка поиска.
- Исключено стандартное серое оформление верхней панели: только для вкладки 2 отрисовывается локальная графитовая заливка поверх общего заголовка.
- Для текущей вкладки 2 используется локальный золотой док; остальные вкладки и глобальные настройки не перерабатывались.
- Уточнены 9-slice границы кнопок и чипов: вертикальные значения меньше, чем у основных панелей, чтобы помещаться в 31–47 единиц высоты.

## Чего не утверждаем до полного QA

Компиляция Unity, отсутствие `GUILayout` исключений, реальные размеры кириллических строк, работа `Resources.Load`, нажатия на орбы, сохранение персонажа и точность пикселей относительно эталона **ещё не проверялись**. Следующая работа — финальная интеграция и исправление очевидных расхождений исходников, после всех этапов — общий запуск тестов и визуальное сравнение.

## Ограничения по согласованному ТЗ

- Все карточки заклинаний/способностей пока используют единую иконку `?`.
- Никаких новых способов каста, ресурсов, классов или переработки JSON.
- `ChangeAbilityUse`, `ChangeSpellUse`, `ChangePactUse`, `ChangeResource` неизменны.
- Никакой публикации APK/изменения updater feed без отдельного разрешения.
