## Подход к исправлению

1. **Один корень большинства наложений — несоответствие `9-slice.border=28` и `GUIStyle.padding=7`.** Не чинить каждую надпись отрицательными отступами. Обновить базовые `AbilityPanel/Card/Gold/Input` и при необходимости специальные экранные варианты.
2. **Два ряда вкладок инвентаря всегда видимы.** Строка 1: «Оружие», «Броня», «Расходники». Строка 2: «Материалы», «Хлам». Переключение только через `requestedInventoryCategory` в Layout event. Не добавлять жесты.
3. **Кошелёк — исключение.** Ни `Wallet`, ни расчёт монет, ни транзакции/пользовательские данные не меняем.
4. **Пиктограммы.** Для интерфейсных действий использовать утверждённые PNG по ID, включая №159 для чата. Не заменять всё на новые случайные Unicode-символы. Полная карта ещё не реализована.
5. **Не публиковать визуальные правки без нативного QA.** Статические контракты проверяют лишь исходники. После коммита выполнить Unity Android и Windows компиляцию и ручной тест на телефоне.
