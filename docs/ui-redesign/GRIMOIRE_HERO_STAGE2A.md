# DnD-VTT — «Тёмный гримуар»: этап 2A (экран «Герой»)

Основа: \`experiment/ui-theme-10053\` / 1.00.53. Рабочая ветка: \`experiment/ui-grimoire-hero\`. Главную ветку и канал обновлений не изменять.

## Реализовано в этом коммите

- Первая видимая компоновка «Героя»: портрет (открывает существующий просмотр арта), имя, класс/уровень/раса, HP с визуальной полосой и быстрым изменением на ±1, КД, инициатива, скорость, опыт и состояния.
- **Скорость одновременно в метрах и футах** (D&D 5 футов = 1,5 м); исходное поле в архиве не меняется. Нестандартные текстовые скорости не парсятся насильно.
- Переходы «Дайсы», «Атаки» и «Развитие». Исходный большой редактор **не удалён**: раскрывается блоком «Сведения о герое · подробности и редактирование» — остаются редактирование имени/расы/скорости, спасброски от смерти, отдых, характеристики и экспорт.
- Цвет элементов наследуется из существующей системы пользовательского акцента \`UiTheme\`. Стили кэшируются в \`UiStyleRoles\` и обновляются вместе с \`GUISkin\`, новые текстуры в каждом OnGUI не создаются.
- Никаких изменений в кошельке и внутренних JSON-механиках. Навигация остальных вкладок и существующие свайпы сохранены.

## Границы реализации

Это **первый работоспособный кодовый прототип** компоновки, ещё без импорта графических PNG из \`Dark Grimoire UI Kit 0.1\`. В качестве основы используются существующие нейтральные GUIStyle и встроенная отрисовка полос; исходные PNG остаются в отдельном согласованном пакете. **Не объявлять полный визуальный редизайн интегрированным.**

Для полной художественной идентичности следующим шагом нужно поместить подготовленные прозрачные панели, рамки, иконки и полосы в Resources/Addressables и подключить их к \`UiStyleRoles\` с учётом 9-slice (16 пикселей), без изменения механик кошелька.

## Проверки

Добавлены \`HeroUiChecks\` и команда \`--hero-ui\` для проверок единиц измерения скорости. Существующий набор .NET автоматически вызывает их в общем режиме. Проверка нативной сборки Unity и физического Android не выполнена в этом сеансе — до релиза обязательна.

## Принцип безопасности

Старый \`ClassicHero\` не удалён и доступен через раскрываемую секцию. Откат Hero-экрана возможен заменой единственной строки маршрутизации в \`LegacySessionPanel.Sheet.cs\`.

## Опциональное подключение готового пакета ассетов

Код подгружает из `Resources/UI/Grimoire` графитовые панели, иконку героя и индикаторы HP/XP. Если ассеты отсутствуют, автоматически рисуется упрощённый стиль через существующие `GUIStyle` — запуск не блокируется. Текстуры из `Resources.Load` не уничтожаются во время смены темы.

Подготовлен отдельный импортный архив **`DnD_VTT_Grimoire_Unity_Import_v0.1.zip`**: 65 PNG, `manifest.json`, необходимые `.meta` и детерминированные GUID. Распаковывать в корень репозитория (внутри архива путь `unity/Assets/Vtt/Resources/UI/Grimoire`). Сам архив предоставляется владельцу отдельно; **в GitHub изображения пока не добавлены**.

Перед выпуском выполнить native Unity сборку, на устройстве проверить крупный текст, диапазоны скорости, открытие старого редактора/отдыха/спасбросков/экспорта, быстрые ±1 HP, переходы вкладок, смену тем и отсутствие изменений кошелька. Существующий Windows UI smoke-тест с координатной проверкой старого HP-редактора требует адаптации к раскрываемой секции. Его прохождение не заявлено.
