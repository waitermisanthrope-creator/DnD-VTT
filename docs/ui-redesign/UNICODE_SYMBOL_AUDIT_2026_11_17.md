# DnD-VTT — аудит пиктограмм и Unicode в Unity IMGUI

**Дата аудита:** 17.11.2026. **Основа:** 40 `LegacySessionPanel.*.cs` и `LegacySessionPanel.cs` ветки `experiment/unity-vtt` после первого исправления «Героя», **до** адресного прохода пиктограмм второй партии. Это исходники, а не Android runtime.

## Что именно проверено

По исходному коду найдены символы диапазонов стрелок, геометрических знаков, знаков-символов и emoji (не кириллица и не вся таблица Unicode). В 17 из 40 файлов с частями `LegacySessionPanel` обнаружено **76 строк** с такими символами вне строк, начинающихся с обычных комментариев. Это **кандидаты** на проблемы с глифами, не 76 доказанных ошибок на устройстве: некоторые стрелки/символы могут прекрасно отображаться.

## Исправления второго прохода, отправленные в исходники

1. **Навыки:** заменить тесный селектор `— / ✓ / ✕2` на `- / П / Э`, где «П — владение», «Э — экспертиза». Статусы `0 / 1 / 2` сохраняются, выбор `skillsData`, пересчёт и обработчики без изменений. Стрелка `▾` убрана, используется компактный ASCII-указатель `>`.
2. **Способности:** «Ячейки заклинаний» получают спрайт ID **20** (книга), «Ресурсы» — ID **16** (молния). Кнопка «Параметры приёмов и магии» уже рисует спрайт `ApprovedGrimoireButton`, поэтому `⚙` из текста убран.
3. **Инвентарь:** состояние «Экипировано» отображается текстом и золотым активным стилем вместо `✓`; `CommerceRules.Equip` не изменён.
4. **Менеджер контента:** «Установлено» — текст без `✓`; сравнение SHA256 осталось прежним.
5. **Герой (предыдущий коммит):** заголовки иконок ID 13, 15, 17, 18, 53, 65, 97; для отсутствующих PNG используется прежняя локальная картинка, а не Unicode.

## Следующие приоритеты

- **P1:** входы/разворачивания/переключатели `Sheet`, `ClassicSheet`, `GrimoireAdvancement` и `Market`: текстовые статусы либо реальные спрайты; не менять значения JSON и строки бизнес-логики.
- **P1:** `Advancement`: серия галочек ✓ в выборе рас, классов и статов — упростить до цветового/текстового состояния.
- **P2:** `BrandSettings`, `Appearance`, `Dice`, `DiceControls`, `ContentManager`: убрать ✓ из подписей, когда уже есть выделенная кнопка. Особая проверка `⌫` на цифровой клавиатуре дайсов.
- **P2:** стрелки ←/→ можно оставлять только после подтверждения на обоих платформах или заменить PNG-кнопками ID 1/2. Нельзя заменить все стрелки невидимыми символами.
- **P3:** оставшиеся экраны `FrontEnd`, `Production`, `Crafts`, `Account` и маленькие служебные элементы.

**Критерий приемки:** на реальных скриншотах Android и Windows нет квадратов/вопросительных знаков вместо UI-пиктограмм, и все клики/состояния редактирования работают. Счётчик строк в C# — лишь контроль покрытия, не доказательство визуальной корректности.

## Третий проход: рынок, развитие, дайсы, выбор заклинаний

**Дата:** 17.11.2026. **Статус:** изменения исходников в `experiment/unity-vtt`, пока без проверки на реальном устройстве.

- **Рынок:** старый тёмный фон модального окна заменён на `AbilityPanel` с safe-area отступами. Выбранные разделы/торговцы и режим покупки/продажи/обмена выделены золотом. Вместо `▾/▸` используются явные подписи `(открыть)/(свернуть)`; закрытие — текстовой кнопкой. Склад, расчёт цен, подписи, сохранение сделки, проверки целостности и `MarketTrade` не изменялись.
- **Развитие:** панели получили общий золотой стиль. Выбор вехи, характеристик, подкласса, владений, черт теперь отмечается золотым выделением, а не `✓`. Процедуры повышения, получения HP, подтверждения уровня и записи героя оставлены прежними.
- **3D-дайсы:** выбор набора и лотка, включённое встряхивание показывают активное золотое состояние; символ `⌫` на цифровой клавиатуре заменён текстом «Удалить» (индекс кнопки 11, старое действие удаления цифры). Выбор темы, физика, акселерометр и сброс движения не менялись.
- **Лист / справочник заклинаний:** в меню выбора кругов убраны `▾` и `✓`, выбранный круг подсвечивается золотом при открытии из новой вкладки способностей. В старых деревьях коллекций `▼/▶` заменены на `(свернуть)/(открыть)`. Маршрут кошелька неизменён.

**Что осталось:** часть стрелок `←/→`, значки статусов и символы в `ClassicSheet`, `Appearance`, `FrontEnd`, `Production`, `BrandSettings`, служебных экранах. Следующий проход — сопоставление стрелок с PNG ID 1/2 и остальные рискованные glyph-вызовы, затем нативный QA. Чистый источник без сомнительных знаков не гарантирует качественной верстки на телефоне.

## Четвёртый проход: старые вкладки листа

- **Классический лист:** кнопка `◉` для показа арта заменена настоящим PNG **№137** (глаз) через `ApprovedGrimoireButton`. При недоступности библиотеки остаётся читабельная подпись «Арт».
- Раскрывающиеся деревья и поле выбора расы теперь показывают слова «открыть/свернуть/выбрать» вместо `▾/▸`; логика `expanded`, `requestedRaceView` и касания не меняется.
- В классической вкладке приёмов заголовок использует спрайт **№19** и общую золотую панель. Состояние подготовки заклинания — золотая выбранная кнопка вместо `✓`; `spell["prepared"]` не изменён по смыслу.
- **Остались:** стрелки навигации, развёртки вне `ClassicSheet`, некоторые галочки в темах и списках; следующий шаг — целевая PNG-подмена и реальный Android/Windows QA, не глобальная строковая замена.
