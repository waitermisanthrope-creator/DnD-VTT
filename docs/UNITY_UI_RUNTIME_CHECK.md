# Реальная проверка Unity UI — 2026-10-25

Работа только в experiment/unity-vtt, база47949d6b; изменения пока локальные.
После предоставления полного доступа сеть/Docker заработали при выполнении вне
sandbox. Ранее сделанный вывод о невозможности запуска оказался преждевременным.

## Что действительно запускалось

С GitHub скачан Windows release1.00.40, SHA256 установщика
`d253d05dec8a27b531a1546c6b7664d4dedb94355cf605d3708f5b3f2eaed613` сверён.
Настроен изолированный Debian trixie/Wine10/Xvfb/D3D11 software runtime.
Сначала открыт неизменённый выпуск, затем отдельная QA-копия player с текущим
runtime C#, скомпилированным Roslyn против DLL этого выпуска. Оригинальная
Assembly-CSharp сохранена. Это **не сборка Unity Editor**, ассеты и сцены взяты
из выпуска40; базовая версия исходника1.00.00 в QA-копии не является новым релизом.

Мышью открыты главная, настройки, оформление и лист; wheel действительно
перемещал содержимое листа. Затем выполнен существующий DesktopUiSmoke с новыми
проверками roster/search/portrait. Только отдельные синтетические профили.

## Исправлено после просмотра работающего клиента

- «Открыть» на узкой карточке переносилось по буквам: заменено на «Лист», кнопка
  включена в измерение текста.
- В portrait кнопкам экспорта требовалось66.57px вместо56: выделено72px.
- «Сброс» поиска не помещался в82px: выделено112px и добавлено измерение подписи.
- Длинное имя в узком листе занимало пять строк: меньший заголовок на полной
  ширине, переключатели рядом с сохранением. Убрана обрезавшаяся версия на narrow UI.
- Категории настроек выровнены по ширине; выбор темы/рамки/цвета сгруппирован
  в компактные сетки вместо длинных столбцов. Из пользовательской подписи убран
  внутренний путь к обоям. Обработчики сохранения/значения настроек прежние.

Первые попытки: Wine8 упал на IsMouseInPointerEnabled; заменён Wine10.
Первый smoke остановился на кириллическом имени PNG; исправлен locale C.UTF-8.
Следующий smoke поймал clipping двух portrait-кнопок; исправление проверено
повторным прогоном. Эти неудачные попытки не выданы за успешные.

Ограничения: Wine не равен нативной Windows, software GPU не равен устройству;
в логе есть ограничения аудио/видео Wine и Curl60 trust, не объявленные дефектами
продукта. Нужны Unity Editor build, нативная Windows и физический Android.
Нельзя считать всю игру/все жесты проверенными по UI smoke. Старые UX40-ошибки
сохранений/механик и полный перенос классов этим блоком не закрыты.

Сцены/.meta/формат сохранений/ключи/Actions/main не менялись. Новые контейнеры и
бинарники находятся вне Git в /workspace/work/unity-runtime. Без push/релиза/merge.
