# 74.00.21 — стены и окружение

Выпуск продолжает 74.00.20. Дополнительная мебель не импортируется.

- Стены: направления / и \, независимые лицевая/обратная текстуры; режим покрытия существующей стены.
- Этажи: видимость выше и ниже в редакторе и игре. При тумане показывается только активный этаж, чтобы не раскрывать неизвестные комнаты.
- Потолок: только под полом следующего этажа. Кисть потолка меняет именно нижнюю сторону верхнего пола. Применяются текстуры пола. В виде сверху потолки скрываются для доступа к комнате.
- Свет: расчёт на правильном этаже, блокировка стеной, пропуск через окно, радиус/сила/выключение, освещение текстур и моделей, корректное затемнение поверхностей без загруженной текстуры.
- Небо: процедурный фон дня с солнцем/облаками, заката, ночи с луной/звёздами; без новых тяжёлых ассетов.

Проверки модели: стороны и диагонали, пустоты потолков, этажи, свет за стеной/окном и на другом этаже, выключение, сохранение. Проверки DOM и предыдущего обыска проходят. Chromium CI проверяет UI и WebGL, делает снимки дня/заката/ночи. Установку на реальном телефоне в этой среде проверить нельзя.
