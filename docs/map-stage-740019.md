# 74.00.19 — первый этап карт

Объём: новый редактор с каталогом A, темы и прозрачность; туман войны с памятью исследованных клеток; обыск по направлению взгляда с тапом и прокруткой; камеры первого/третьего лица и сверху.

Восстановлен сохранённый код, а не начата разработка заново. Существующие пять готовых карт доступны из раздела «Карты». Каталог этого выпуска использует существующие ресурсы; импорт дополнительных 430 моделей отложен.

Проверки: синтаксис JS; модель видимости, перенос добычи и откат при ошибке сохранения; DOM редактора, темы, камера, обыск, отмена действий. Реальную установку на телефоне проверяет пользователь.

Далее отдельными этапами: мебель; улучшения строительства; освещение и окружение. Не объявлять эти этапы завершёнными по наличию вспомогательного кода.
