# Дерево рынка и мод фэнтезийных торговцев — 11.11.2026

**Статус: код внесён в experiment/unity-vtt, НЕТ проверенного Android/Windows билда. Не выпускать без тестирования.**

## Поручение владельца

В окне «Торговля» раскрывающийся каталог вида **Оружие → Оружейник → товары**,
**Броня → Кожевник → товары** и аналогично для других разделов.
Применить предметы уже установленных библиотек мастерской, не дублировать
в моде тысячи записей. Оригинальные торговцы и сохранения не удалять.
Скриншот исходного дефекта: «Торговля недоступна… неизвестное или слишком большое числовое значение торговли».

## Изменения

- `unity/Assets/Vtt/Runtime/WorkshopStore.cs`: новый проверяемый декларативный
  тип JSON-пакета `market`; `Commerce()` передаёт список пакетов на worker.
- `LegacySessionPanel.ContentManager.cs`: фильтр «Торговцы» в мастерской.
- `LegacySessionPanel.Commerce.cs`, `InventoryCatalogCache.cs` (второй без изменений):
  объединение рынка с проверенными `item`-пакетами выполняется в фоне.
- `CommerceRules.Market.cs`: список новых предложений через исходный
  `sourceItemId`, без копий определений. До 32 новых предложений на торговца,
  только при наличии проверенной стоимости. Отсутствующая цена не заменяется
  вымышленной. Стоимость ПМ/ЗМ/ЭМ/СМ/ММ и поле
  `itemTraits.trade.basePriceGp` поддерживаются. Склад старого персонажа
  не сбрасывается при появлении новых позиций.
- `LegacySessionPanel.Market.cs`: настоящее вложенное раскрытие категории,
  торговца и списка предложений; режимы «Купить/Продать/Обмен» оставлены.
  Ошибка цены отдельного товара не блокирует весь рынок.
- `unity/Assets/Vtt/Editor/WorkshopEditorValidation.cs`:
  `ValidateMarketMerchantMod()` — синтетический контракт.
- Сопутствующий репозиторий
  `waitermisanthrope-creator/DnD-VTT-Content`, **ветка
  `feature/fantasy-merchant-market-v1`**, файл
  `packages/dnd.market.fantasy-merchants-1.0.0.json`:
  12 разделов, 45 торговцев (42 исходных + экзотический оружейник,
  швея/портной, лекарь).
  `catalog/v3/index.json` изменён **только в отдельной черновой ветке**;
  живой Content/main не менять до проверенной Unity версии 1.00.50+.
