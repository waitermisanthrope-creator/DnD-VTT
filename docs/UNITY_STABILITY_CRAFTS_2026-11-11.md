# Стабильность Android и ремёсла: утверждённая задача

База: experiment/unity-vtt c2011273, опубликованная1.00.50. Main не менять. Релиз/публичный канал/approval не менять. Все коммиты разработки [skip ci]. APK только тестовый с новым номером после проверок.

## Этап0 — исследование

UI — LegacySessionPanel partial/OnGUI, общий Branding + SheetSkin + ClassicSheet, Texture2D принадлежат brandStyleTextures. Подтверждённый дефект: pause(false)/focus(true) вызывают InvalidateBrandStyles; EnsureBrandStyles уничтожает ВСЕ Rounded-текстуры, но clone/coin/market GUIStyle остаются в кэше. Исправление: общий отложенный restore readable текстур без уничтожения стилей при возврате. Физический Android для подтверждения context loss/блокировки недоступен; добавить воспроизводимую проверку5циклов callbacks и снимки в существующий runtime smoke.

Навигация — Touch.cs/MenuGesture, единый арбитраж оси/минимального viewport/native input. ClassicSheet хранит ID страниц отдельно от подписей; сохранить старые ID, добавить ремёсла ID10 между inventory3/notes4. Свайп должен использовать существующий арбитр; плавный snap не должен сохранять промежуточную страницу. Проверить историю до реализации.

Дайсы — Dice.cs UpdateDiceTable уничтожает весь стол на каждом уходе со страницы. DrawDiceTable создаёт scene/mesh/materials и синхронно читает/проверяет все наборы/лотки повторно. Оставить один ограниченный по времени кэш стола, остановить hidden tick/sensor; освобождать по lowMemory/destroy/TTL. Данные наборов готовить в фоне из снимка Installed, общие предметы не копировать. Реальные timings записывать в runtime smoke, не называть их замером телефона.

Крафт/алхимия — CommerceRules partial (clone-then-commit Craft/Profile/Mix/Research), тип мода craft, modes craft-v31/alchemy-v30/alchemy-ingredients. WorkshopStore.Commerce + InventoryCatalogCache уже создают единый item/craft/market snapshot в фоне. Расширить craft JSON декларативным режимом производства, не новым менеджером модов. Предметы/пакеты имеют существующие ID/provenance. Рабочие JS-профессии v38, progression v47, economy v49 — референсы, развитие Homebrew опционально.

Контейнеры — inventory.containers[].contents. Не использовать старый AddItem merge по части полей: варианты с charges/durability могут сливаться. Перенос на detached archive с полным сравнением идентичности, резервной копией ДО записи, сохранением старых записей и marker; archived contents исключить из активного веса. Идемпотентность и отказ без мутации при неизвестном формате обязательны.

Рынок50: дерево/необязательный мод45торговцев/12разделов, цены разных валют и изоляция плохого stock; сохранить owned-JObject fixes90da2164/908836a9. Проверить существующими Market/Commerce/CollectionChecks, экономику не переписывать.

Сетевой мастер: текущая Unity имеет auth/own-character cloud sync/chat, но не транспорт кампании/авторитетного GM approval. Cloud admin не GM. Реализовать явное локальное/offline подтверждение и декларативный запрос/решение с повторной валидацией; онлайн-подтверждения нельзя объявить готовыми без серверной кампании.

1. Общий lifecycle UI + regression5cycles.

3. Ограниченный кэш/ленивая подготовка дайсов + runtime metrics.
4. Безопасная миграция контейнеров, извлечение старых крафта/алхимии на страницу10.
5. Декларативные профессии/рецепты/проекты в CommerceRules, JSON моды, три режима/локальные политики/approval/cancel, атомарные ID-based операции и история.
6. UI ремёсел: режимы, профессии, известные/доступные/избранные, проекты, ограниченные списки, ручной учёт и старые инструменты алхимии.

Данные персонажа расширяются crafts объектом; неизвестные поля/старые профессии остаются. Повторный commit проекта ничего не списывает/не выдаёт. Отмена до одобрения/завершения не меняет инвентарь. Пользовательский код запрещён. Стандартные профессии без обязательных уровней; правила2014/2024/Homebrew выбираются данными.

## Этап1 — исходники исправлены

Resume/focus больше не запускают уничтожение общих фонов; общий Layout-time restore повторно загружает readable текстуры, сохраняя ссылки GUIStyle. Незавершённый pointer сбрасывается при паузе/потере фокуса. Регрессионный контракт воспроизвёл ошибку до фикса, после фикса UI_LIFECYCLE_CONTRACT_PASS2. Android+Windows C# compile против реальных Unity DLL PASS. В runtime smoke добавлены6циклов pause/focus с проверкой существования/идентичности реального Texture2D и кадрами ui-resume. Эти runtime проверки ещё не выполнены; физические pause/lock-screen недоступны.

## Этап2 — общий свайп страниц

История native fd9b9301/986bec6e/705ab4f2/47949d6b содержит арбитраж scroll, но не утраченный snap. Поведение восстановления сверено с WebView a3753ed0 (app/app.js): реальный список страниц, dominant horizontal, clamp, порог40. Native продолжает использовать MenuGesture и requestedSheetTab. SheetSwipeMotion содержит только анимацию, не выбранную страницу: drag → выход → Layout commit существующей навигации → вход/snap0. Header и вложенные scroll/поля сохраняют владение; рынок/диалоги не регистрируют page region; viewport дайсов исключён. Pause/focus-loss отменяет незавершённый snap. Длина/границы берутся из classicTabs, поэтому новая страница включается одним списком. SHEET_SWIPE_PASS191, обе conditional compile PASS. Физические свайпы Android ещё не проверены.

## Этап3 — дайсы

Стол сохраняется один при смене вкладок; hidden physics/render/sensor не обновляются, TTL120сек освобождает неактивный стол без незавершённого броска, lowMemory/destroy освобождают ресурсы. Удаление модов не уничтожает текущий незавершённый бросок; каталог инвалидируется и восстанавливается отдельно. Первое создание отложено на кадр для немедленного ответа UI, один первоначальный preview вместо повторов. Каталоги appearance читаются worker из одного Installed snapshot, сторонние item/model payload не читаются; PNG повторно не декодируется при чтении уже проверенной metadata. Только выбранный набор гидратируется в фоне, GPU материал ставится на главном потоке после окончания броска. Старые Read/Data hash проверки сохранены. DICE_LOADING_PASS2, обе conditional compile PASS. В DiceValidation добавлен реальный native renderer benchmark old initialization vs optimized/retained; DesktopUiSmoke измеряет first/reopen и проверяет идентичность стола. Эти runtime замеры ожидают сборки; Android timing неизвестен, <1сек на телефоне не заявляется.

## Этап4 — инвентарь и перенос

Ремёсла ID10 добавлены между3/4 без сдвига старых ID; прежние DrawCrafting/DrawAlchemy вынесены на самостоятельную страницу. В материалах инвентаря нет автоматической загрузки/отрисовки ремёсел. Управление контейнерами убрано, вместо него только подтверждаемый безопасный перенос старых данных. Detached-copy + полное сравнение вариантов предметов + перенос сумки как обычного предмета; оригинал containers/contents сохраняется с подписью и marker. Активный вес не дублирует архив. Долговечный перенос: общий write lease, проверка актуальности архива, timestamp backup всех героев, прежний atomic .pending/.bak writer. Ошибка записи сохраняет исходный файл и original archive. Повторный перенос идемпотентен; изменённый архив контейнера блокирует повтор. Проверка необходимости кэшируется по immutable archive/hero, не хэширует содержимое на каждом кадре. CONTAINER_MIGRATION_PASS13; обе conditional compile PASS.
