# V74.00.14 — текстуры кожи MakeHuman, 2026-10-09

## Причина однотонного человека
Исходный `human-base-rigged.glb` содержит один серо-голубой материал
(baseColorFactor ≈ [0.48, 0.51, 0.54, 1]), не содержит images/textures, но содержит
корректный TEXCOORD_0 для всех 70 985 вершин. Это подтверждено чтением реального GLB.

## Изменения
- Две исходные PNG 2048×2048 и их `.mhmat` из пользовательского архива размещены
  в `app/assets/3d/makehuman/skins/`. CC0-описание сохранено в материалах и README.
- В `character_system.js` добавлены реестр кожи и skinId в сериализацию/render descriptor.
  Старые персонажи получают мужскую текстуру по умолчанию. Кожа относится только
  к человеческому материалу 0; остальные расы не наследуют её.
- В редактор добавлен выбор «Мужская кожа / Женская кожа»; это выбор текстуры,
  а не новая геометрия или переключатель морфов пола.
- Для кожи используется белый multiplier, чтобы серо-голубой baseColorFactor не
  затемнял изображение. Никакого изменения оригинального GLB.
- glTF-текстуры загружаются без вертикального переворота. При fallback Uint32 →
  drawArrays разворачиваются и позиции, и UV по одним и тем же индексам.
- GL-ресурсы освобождаются при закрытии/сбросе; старые async callbacks не затрагивают
  новый редактор. Ошибки текстуры остаются видимыми после последующих redraw.
- Android versionName/versionCode: 74.00.14 / 7400014; cache-busters редактора и системы
  персонажа обновлены. Новые текстуры лежат под app/, поэтому включены и в APK, и в OTA.
