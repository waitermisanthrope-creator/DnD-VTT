## Сделано в этапе 1
- Прочитан текущий guide и исходники V74.00.15. Женская кожа уже есть, но поле
  `gender` пока не меняет геометрию; UI-переключатель кожи не считается женской моделью.
- В оригинальном `human-base-rigged.glb` найдены MPFB_HUM_* extras. Это мужчина
  gender=1, age≈0.46, muscle≈0.43, weight≈0.49, proportions≈0.58, height=0.5,
  cupsize=firmness=0.5; ancestry caucasian/asian/african≈0.7/0.2/0.1.
- `tools/prepare_makehuman_gender.js` читает эти настройки, воспроизводит
  интерполяцию MPFB (компоненты округляются до 4 знаков, cutoff >0.01) и вычитает
  исходный macro stack из женского. Возраст/телосложение/ancestry сохраняются.
  Учитываются race-gender-age, universal и proportions; height/cupsize/firmness
  в этом первом preset должны оставаться нейтральными, другие входы отклоняются.
- `tools/build_makehuman_morphs.js` расширен декларативным составным target:
  `{target: "human-female", sources: [{folder, name, weight}, ...]}`.
  Поддерживаются отрицательные веса, Float64-суммирование до переноса, SHA256
  каждого исходного target. Используется прежний общий UV barycentric map.
  Четыре прежние парные оси остаются в dndMorphChannels; именованный составной
  target передаётся через общий механизм прямых target names.
- Готовый рецепт — `tools/makehuman_gender_channels.json`: 8 прежних targets
  плюс `human-female`, собранный из 28 взвешенных sources (14 исходного и 14 женского
  stack). Исходные данные MPFB взяты из того же commit
  `d0a32e57a7f915cb2f2b95410e2117648c7bbb7e`, core assets CC0.
- Тестовый GLB собран отдельно, без изменения original/shipped GLB. Он не
  подключён в приложение и не опубликован через OTA. Его можно воспроизвести
  командами ниже; scratch-файл не считать сохранённым production-ассетом.
