# [ВЫПОЛНЕНО] Первый блок повседневных действий с персонажами — Unity 1.00.39

Ветка: `experiment/unity-vtt`. Владелец поручил идти по ближайшему списку: доставить удаление и довести создание, выбор, лист, сохранение, импорт и резервные копии.

## Изменения

- Найдена точная причина исходной жалобы: `DrawBrandHome` намеренно устанавливал `GUI.enabled=false` вокруг крестика во время визуального порта. Крестик теперь вызывает общий запрос удаления и открывает подтверждение с именем героя. Отмена не меняет архив. Отдельный список использует тот же обработчик.
- Удаление работает по ID через отдельный кандидат архива. Сначала атомарная запись на диск, затем замена открытого архива и выбор оставшегося героя. Пустой список сохраняется и читается после удаления последнего героя.
- Обычные правки листа и подтверждённое удаление его записей сохраняются автоматически. Ошибка записи не меняет открытый архив. Кошелёк и торговля сохраняют свои прежние транзакции.
- Импорт добавляет героев к текущему архиву и сразу сохраняет результат. Полностью одинаковый повторный импорт не создаёт дублей. Другая версия существующего ID отменяет весь импорт с сообщением; неизвестные поля остальных героев и обёртки сохраняются.
- В разделе данных доступны независимая резервная копия в файл и подтверждённое восстановление предыдущего `.bak`. При восстановлении прежний текущий файл становится резервной копией для отмены восстановления. Повреждённый резерв не перезаписывает текущие данные.
- Повторное сохранение идентичного JSON не перезаписывает последнюю резервную копию.
