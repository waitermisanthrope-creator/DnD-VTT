## Что сделано

- В новом наборе Бездна щупальце находится в каждой вершине: d4=4,d6=8,d8=6,d10=12,d12=20,d20=12; d100 — два d10. Нижняя часть деформируется по поверхности. Контактный импульс действительно воздействует на Rigidbody и может изменить результат перед его фиксацией. Усиленная анимация сохраняется после остановки, принятый результат остаётся неизменным.
- Слайм многократно подпрыгивает с настоящей физикой, сохраняя желейную деформацию. Активные фазы запускаются при попадании в приёмный лоток, поэтому спуск по башне их не расходует. После принятия результата продолжается декоративная анимация.
- До20 физических тел одновременно вместо2/4/8. Процентная пара занимает2места. Общее количество не ограничивается: BigInteger-протокол подаёт более крупные запросы партиями, смешанные типы и повторяющиеся группы сохраняются.
- В мастерской четыре отдельных пакета: винтовая башня, башня с ямой/наклонными перегородками, шестигранный и восьмигранный лотки. Четыре процедурных принта. Пол многоугольных лотков — настоящий замкнутый выпуклый многоугольный объём, совпадающий со стенками и коллайдером.
- Кубики на поднятых ступенях ещё не считаются завершёнными. Ограниченные реальные толчки помогают освободить застрявшие тела; неоднозначный кубик перебрасывается в найденное свободное место приёмного лотка. Порог чтения грани не понижался ради прохождения теста, значение не подбирается программно. Уже зафиксированные тела не перебрасываются.
- Встряхивание включается отдельно. Фильтр удаляет гравитацию, требует повторных разнонаправленных движений и выпускает один бросок после остановки телефона. Сила/длительность влияют на ограниченную начальную инерцию; в процессе броска возможен дополнительный подброс. Отмена, сворачивание и потеря фокуса сбрасывают незавершённый жест. Датчик отключается только если его включил этот экран. При отсутствии датчика действие явно недоступно.

## Как пользоваться

1. Обновить Unity-приложение до1.00.32 через штатную проверку обновлений.
2. На экране дайсов выбрать «Мои наборы». Для живых профилей нужны Бездна/Слайм1.2.1; уже установленные1.2.1 перескачивать не нужно. Старые1.0/1.1 сохраняют прежнее поведение для совместимости.
3. Мастерская → Оформление → Лотки и башни → скачать нужный пакет. Затем на экране дайсов «Лоток / башня» → выбрать установленный вариант. Выбор сохраняется отдельно от набора кубов и иконки приложения.
4. «+ Добавить дайс» → грани и количество. Например7d20+3d6+1d8 или20d20. Кнопочная клавиатура количества сохраняется; экранная клавиатура телефона не нужна.
5. Для управления движением нажать «Включить встряхивание телефона», несколько раз встряхнуть и остановить телефон. Кнопка обычного броска остаётся доступной при отсутствии датчика.

## Ограничения и оставшаяся проверка

Физический Android-телефон здесь не подключён. Чувствительность реального датчика, производительность20кубов(особенно20d12Бездны), касания/GPU/возврат из фона и установка поверх текущей телефонной версии требуют проверки владельцем. Синтетический InputSystem-тест проверяет жизненный цикл устройства, не чувствительность настоящего акселерометра. Интерактивный Windows GPU и Authenticode не заявляются проверенными.

Щупальца используют облегчённую контактную модель с деформируемой оболочкой, до3 импульсов на кубик в ограниченной активной фазе; полного soft-body/self/cross-arm collision solver нет. Физическая серия слайма конечна, дальнейшее движение декоративное.20 одновременных тел — бюджет мобильной стабильности; общее количество запросов остаётся неограниченным. Башни — базовые процедурные модели, не готовые художественные AssetBundle-модели. Фигурные наборы не сертифицированы как равномерные; сетевого подтверждения результата нет.

Прошлые Android-прогоны выявили неверную проверку цвета общего вида, зависание/повторные столкновения в башне; причины исправлены. Кандидат31 прошёл сборки, но визуальная проверка выявила прямоугольную подложку многоугольных лотков: он не включался в feed, его публичные файлы сохранены неизменными.32исправляет форму пола и прошёл повторную проверку.
