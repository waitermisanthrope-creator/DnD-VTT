Рядом «Все дополнения», отдельные части доступны переключателем. 6729 существующих предметов / 103 исходных пакета, без смены ID. Каталог Content v3 сохранён, опубликованы семь метаданных сборников с minClientVersionCode10035 (Content c01daff).

Установка сначала проверяет весь граф зависимостей/совместимость/свободное место, затем скачивает и проверяет пакеты по одному, корневой маркер последним. Повтор пропускает проверенные версии; после ошибки можно продолжить. Удаление маркера сохраняет части. Новая механика ремонта не входит в изменение.
