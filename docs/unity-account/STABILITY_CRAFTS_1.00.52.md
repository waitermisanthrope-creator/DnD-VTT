## Выполненные изменения и исправленные баги

1. **Общий UI.** Найден разрушительный путь resume: освобождались фоны, на которые продолжали ссылаться другие кэши GUIStyle. Resume сохраняет живые ссылки и восстанавливает загрузку читаемых текстур. При настоящей смене темы единый типизированный метод сбрасывает все кэши стилей. Исправлена обнаруженная native QA регрессия51: готовый sheetSkin больше не заменяется базовым скином при обычном рисовании. Размеры/цвета/позиции контролов ради этого не менялись.
2. **Навигация.** Свайп и плавная фиксация используют прежний MenuGesture и единственный requestedSheetTab. Вертикальная прокрутка, вложенные области и поля сохраняют арбитраж; пауза/потеря фокуса отменяют незавершённый жест. Старые ID страниц сохранены; новая страница включена в общий список.
3. **Дайсы.** Один стол сохраняется при переходах, с TTL120сек/lowMemory/destroy освобождением. Скрытый уже начатый бросок завершается без рендера, затем физика останавливается. Первое создание отложено для ответа UI; каталог/декодирование оформления готовятся в фоне. Бросок ждёт выбранное оформление, чтобы первая загрузка не использовала временный классический вид. Типы дайсов, материалы, лотки, результаты и старые правила бросков сохранены.
4. **Инвентарь.** Ремёсла вынесены отдельно; кошелёк, рынок, справочники, предметы и вес остаются. Управление контейнерами скрыто. Перенос по подтверждению создаёт резервную копию всего архива, сохраняет исходные записи и все свойства вариантов, объединяет только полностью одинаковые предметы и не повторяет выдачу при новом запуске. Неизвестный формат/конфликт записи отклоняется без изменения исходника.
5. **Ремёсла.** Страница между инвентарём и заметками: три сохраняемых режима, профессии, каталог, поиск/известные/доступные/избранные рецепты, проекты, игровые часы, ручной итог, отмена, архив и история. Списки постраничные, каталог ленивый. Старые Craft/Mix/Research включены через адаптер; их механика и сведения о составе/инструментах/СЛ сохранены.
6. **Производство.** Расход/результат сохраняются атомарно на копии архива с проверкой актуальности файла. Проверяются материалы, инструменты, условия, стоимость, версия рецепта; повторное завершение/архив проекта не создаёт предметы заново. Ручной режим применяет только явно выбранные изменения, полуавтомат ждёт локального мастера, автомат выполняет правила рецепта. Поддержаны необязательный опыт/уровни/модификаторы/открытие рецептов, цепочки обычных предметов и сохранённые долгие проекты.
7. **Homebrew.** Декларативные JSON-профессии/рецепты/предметы используют существующий WorkshopStore, ID, версии, зависимости, контроль целостности и удаление. Рецепты ссылаются на общие itemId. Произвольный код не исполняется. Формат и примеры: `docs/UNITY_PRODUCTION_FORMAT.md`, `unity/ContentSources~/production-examples/`.
8. **Рынок50.** Торговый движок, цены и данные рынка не переписывались. Сохранены дерево,45необязательных торговцев/12разделов, валюты и исправления остатков. Авторизация, классы, расы, дополнения и старые поля персонажей не удалялись.

## Известные ограничения и незавершённая работа

- Физический Android недоступен: пять настоящих сворачиваний/возвратов, блокировка экрана, touch-свайпы и замеры телефона **не выполнены**. Callback-тесты не заменяют устройство. Выпуск сделан по прямому запросу владельца для такой проверки.
- Удалённое одобрение мастера и авторитетные ограничения сетевой кампании **не реализованы**: у текущего Unity нет транспорта/полномочий кампаний. Готова явно обозначенная доверенная локальная передача устройства мастеру; cloud admin не подменяет GM.
- Это не заявление о наличии всех официальных рецептов2014/2024. Ядро поддерживает декларативные редакции/системы, книга использует установленные сборники и собственные JSON. Визуальный редактор рецептов в приложении не добавлялся.
- Полностью готовым к сессиям приложение по одной сборке не объявляется. Windows52 UI QA и перечисленные физические проверки остаются обязательными для окончательной приёмки.
