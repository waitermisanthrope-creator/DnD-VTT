## Серверные префиксы

Владелец уже сообщил успешное применение миграции ников 202610220001. Для новых префиксов выполнить целиком `supabase/migrations/202610220002_chat_staff_badges.sql` в SQL Editor того же проекта. Файл меняет только существующую функцию чтения чата; ключи, назначения staff, сохранения и очистка сообщений не меняются. Повторное применение безопасно.

Проверка из SQL Editor:

```sql
select position('roleBadgesSupported' in pg_get_functiondef('public.read_chat()'::regprocedure)) > 0 as staff_badges_ready;
```

После true обновить глобальный чат в приложении. Владелец: золотой префикс с мягким свечением/пульсацией; заместитель: золотой; модераторы 0/1/2/3: голубой/зелёный/фиолетовый/коралловый. Обычный игрок без префикса. Источник — только активная строка app_private.staff, ник и user_metadata не учитываются. Отзыв назначения убирает префикс при следующем чтении. При отсутствии миграции приложение не придумывает роли и показывает состояние подключения.

## Ввод

На Android кнопка написания/редактирования черновика открывает системное многострочное поле: касание для курсора, долгое нажатие для выделения/копирования/вставки, Готово или Отмена. Отправка отдельно, после закрытия редактора. Во время подтверждения отправки редактирование заблокировано; успех очищает черновик, ошибка оставляет текст и ID безопасного повтора. На Windows выделение мышью внутри поля не прокручивает страницу. Редактирование уже опубликованных сообщений не добавлено; исправляется ввод черновика. История по-прежнему один час.

## Основная иконка Android

Вместо создания pinned shortcut переключаются фиксированные activity-alias, как в WebView. Исходное имя Activity сохраняется как стандартный alias; настоящая Unity Activity переносится в совместимый подкласс с прежними настройками. Одновременно активен один launcher entry. Android 13+ меняет состояния атомарно; старые версии сначала включают выбранный вариант и откатывают состояния при ошибке. DONT_KILL_APP; package name, сертификат и данные приложения сохраняются.

Android требует системные изображения внутри APK: только 31 уменьшенный вариант 192×192, создаваемый при сборке из проверенных опубликованных пакетов. Полные изображения по-прежнему загружаются из мастерской. Это необходимое исключение для launcher icons, не перенос полного набора обоев обратно в APK. Контроль бюджета — 3 MiB и фактические размеры в APK.

Ранее созданный отдельный закреплённый ярлык Android не разрешает удалить программно: пользователь удаляет его вручную. Новые закреплённые ярлыки код не создаёт. Расположение/задержка обновления основной иконки зависит от launcher; физическая проверка требуется. Windows: только предпросмотр и экспорт PNG, системная иконка не меняется.

## Мастерская

Дерево: Персонажи → расы/классы/подклассы/черты; Инвентарь → оружие/броня/расходники/материалы/хлам; Крафт и алхимия → рецепты, алхимия → ингредиенты/правила; 3D и карты → карты → тип локации, модели, материалы, окружение, анимации; Оформление → обои/иконки. Показываются группы реально опубликованного содержимого, без неработающих пустых разделов. Страницы по 12 и кеш фильтрации сохранены.

75 текущих графических JSON-пакетов имеют отдельные JPEG-предпросмотры: суммарно 672,045 байт. Обои/иконки — уменьшенные исходные изображения; карты — подписанная схема первого этажа, примитивы — подписанная схема объектов; материалы — реальные цветовые образцы. Не выдаются за финальные 3D-скриншоты. Источник/лицензия/автор/исходный SHA сохранены в release preview-index.json.

Клиент загружает последовательно только миниатюры текущей страницы (не полные пакеты). Размер ≤256 KiB, сторона ≤512, проверяются SHA-256 и JPEG-размер до декодирования. Кеш изображений ограничен текущей страницей, временный дисковый кеш — 8 MiB; выход/переход/уничтожение освобождают текстуры и удаляют временную папку. После аварийного завершения остаток очищается при следующем открытии мастерской. Установленные пакеты и сохранения не удаляются. Ошибки предпросмотра допускают повтор, скачивание самого пакета работает отдельно.
