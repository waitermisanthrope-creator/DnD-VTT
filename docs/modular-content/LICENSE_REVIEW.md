# Проверка происхождения — 2026-10-20

Публикуются только собственные demo JSON и шесть MakeHuman skin/license/metadata файлов с явными исходными CC0 сведениями. Остальные файлы не объявляются автоматически свободными.

Для Quaternius проверены первичные страницы:

- [QAL v1.0](https://quaternius.com/license.html), дата страницы 28 августа 2026: использование в игре разрешено, отдельное распространение assets/asset packs ограничено. Раздел 7 отдельно сохраняет прежние условия для ранее полученных материалов. Это относится к ресурсам под QAL, не отменяет автоматически существующее CC0 разрешение.
- [Fantasy Props MegaKit — страница автора](https://quaternius.com/packs/fantasypropsmegakit.html) по-прежнему явно указывает CC0 для этого набора.
- [Fantasy Props MegaKit — itch.io автора](https://quaternius.itch.io/fantasy-props-megakit) также указывает CC0 и различает Standard/Pro/Source состав.

Следствие для проекта: одно имя папки `quaternius` не определяет лицензию. Наименования и четыре набора Trim-текстур похожи на Fantasy Props MegaKit, но точный архив-источник, редакция и побайтовое соответствие локальных файлов ещё не подтверждены. Не переносить их в публичный standalone asset repository только по этому предположению. Следующий проверяемый шаг — получить исходный разрешённый архив, сохранить его лицензию/автора/URL/хеш и сопоставить файлы (или задокументированные производные). Никаких оплат или сообщений автору этим запуском не выполнялось.

Для коммерческих OST/MP3, корневых GLB и изображений классов отдельного подтверждения прав в репозитории не обнаружено. Они не включены в новые публикации. Их наличие в исходном репозитории не является доказательством разрешения на отдельное распространение.
