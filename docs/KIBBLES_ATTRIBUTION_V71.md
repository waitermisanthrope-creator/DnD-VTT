# KibblesTasty content attribution

This project includes a structured, localized integration layer for KibblesTasty classes.

- Creator: KibblesTasty
- Official site: https://www.kthomebrew.com/
- Kibbles Reference Document: https://www.kthomebrew.com/krd
- Public structured reference used for class progression cross-checks: TheGiddyLimit/homebrew (KibblesTasty class JSONs).

The application stores internal IDs for compatibility with existing saves and presents Russian display names to players.
The integration intentionally uses concise, original mechanical summaries and structured feature metadata rather than embedding complete book text.

Before redistributing a build, review the current permissions and licensing terms of each source and of any additional KibblesTasty content added later.
