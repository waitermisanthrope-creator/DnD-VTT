# Незавершённая работа по 3D-расам

Обновлено для 74.00.53. Это перечень оставшихся задач, а не список полностью готовых рас.

## Общие задачи

- Перенести расовые профили и материалы из редактора на модель персонажа на карте.
- Настроить retargeting человеческих анимаций под изменённые пропорции; проверить стопы, оружие, idle, ходьбу и действия.
- Сделать расовые анимации плавания, полёта, прыжков и особых форм там, где они нужны.
- Проверить реальные Android/FPS, крайние морфы и пересечения всей одежды. Браузерные проверки не заменяют проверку телефона.
- Завершить отдельные карты кожи и анатомические модули: зубы, рога, хвосты, крылья, перепонки, шерсть и перья.
