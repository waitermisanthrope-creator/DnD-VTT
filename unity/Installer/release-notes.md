# DnD VTT Unity 1.00.00

Первый устанавливаемый экспериментальный Unity-клиент для Android ARM64 и Windows x64.

- Главный экран, список героев и создание персонажа первого уровня.
- Лист, характеристики, навыки, магия, инвентарь, кошелёк и заметки.
- Настройки графики/камеры и отдельная 3D-карта.
- Подготовлен отдельный канал обновлений Unity: проверка версии и SHA-256, установка поверх приложения с сохранением локальных данных.

Android: `DnD-VTT-Unity-1.00.00-arm64.apk`, Android 8+ / ARM64. Windows: `DnD-VTT-Unity-Setup-1.00.00-x64.exe`, Windows x64, установка в профиль пользователя. APK подписан отдельным постоянным ключом Unity. Windows Setup не имеет Authenticode-подписи.

Полная эквивалентность WebView ещё не достигнута: классовая автоматика, повышение уровня, игровые эффекты и облачная синхронизация требуют продолжения. Физическая проверка на Android-устройстве не выполнена. Это предварительный релиз Unity, он не заменяет стабильные релизы прежнего клиента.
