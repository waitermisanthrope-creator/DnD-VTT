## Интеграция

`Assets/Editor/ApprovedIconImporter.cs` вызывается автоматически при сборке Android и Windows через `Assets/Vtt/Editor/UnityReleaseBuild.cs`. Он сначала проверяет полный ZIP, затем синхронно импортирует спрайты в **`Assets/Vtt/Resources/VttIcons/`**, игнорируемый Git (исходный ZIP уже хранится в репозитории).

`ApprovedIconRegistry.GetSprite(id)` загружает `Resources.Load<Sprite>("VttIcons/icon_" + id.ToString("D3"))`. Работающие `ApprovedGrimoireButton` и поиск на странице «Способности и магия» используют картинки при наличии. Кнопки остаются IMGUI-кнопками: графика не меняет обработчики. Существующие рамки сохраняются; в иконках нет новых рамок.

Для проверки импорта: `python unity/ci/test_approved_icon_pipeline.py` и `python unity/ci/validate_approved_icons.py unity/DnD-VTT_160_icons_complete.zip` (последняя требует Pillow). Эти проверки **не доказывают фактический Android/Windows рендер**.
